Llama 3.2 — Model Overview

Llama 3.2 is Meta's latest family of open-source large language models,
released in September 2024.

Available Variants:
- Llama 3.2 1B  : Lightweight, fast, ideal for edge devices
- Llama 3.2 3B  : Balanced performance and speed
- Llama 3.2 11B : Multimodal (text + vision), high capability
- Llama 3.2 90B : Largest, best quality, requires significant hardware

Key Features:
- Open weights — download and run locally
- Instruction-tuned versions available (better for chat/RAG)
- Context window: up to 128K tokens
- Multilingual support
- Tool calling / function calling support

Running Locally with Ollama:
  ollama pull llama3.2        # pulls the 3B model (default)
  ollama pull llama3.2:1b     # pulls the 1B model
  ollama pull llama3.2:11b    # pulls the 11B model (needs ~8GB RAM)
  ollama serve                 # starts the local API server

Hardware Requirements:
- 1B model: ~1GB RAM, runs on CPU
- 3B model: ~2GB RAM, runs on CPU (slow) or GPU
- 11B model: ~8GB GPU VRAM recommended
- 90B model: ~64GB+ VRAM (multiple GPUs)

API Endpoint (via Ollama):
  Base URL: http://localhost:11434
  Chat:     POST /api/chat
  Embed:    POST /api/embed
